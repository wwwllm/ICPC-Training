# 后缀数组（SA）

## 定义

后缀数组将非空字符串的所有后缀按字典序排列，可用于处理子串排序、最长重复子串和最长公共子串等问题。该实现使用倍增法构造后缀数组，并使用 Kasai 算法求相邻后缀的最长公共前缀，时间复杂度为 $O(n\log n)$，空间复杂度为 $O(n)$。

## 实现

所有数组均从 0 开始，下标和数组值都是原字符串中的位置：

- `sa[i]`：字典序第 `i` 小的后缀在原字符串中的起点。
- `rk[i]`：起点为 `i` 的后缀在 `sa` 中的排名，即 `sa[rk[i]] = i`。
- `lc[i]`：相邻后缀 `sa[i]` 与 `sa[i + 1]` 的最长公共前缀长度，因此其长度为 `n - 1`。

倍增过程中按第二关键字和第一关键字进行基数排序，每轮将已比较的前缀长度翻倍。代码要求字符串非空，并使用 C++23 的 `ranges::iota`。

### 代码

```cpp
struct SA
{
    int n;
    vector<int> sa, rk, lc;
    SA(string &s) : n(s.size()), sa(s.size()), rk(s.size()), lc(s.size() - 1)
    {
        ranges::iota(sa, 0);
        ranges::sort(sa, [&](int a, int b)
                     { return s[a] < s[b]; });
        rk[sa[0]] = 0;
        for (int i = 1; i < n; i++)
        {
            rk[sa[i]] = rk[sa[i - 1]] + (s[sa[i - 1]] != s[sa[i]]);
        }
        int k = 1;
        vector<int> tmp, cnt(n);
        tmp.reserve(n);
        while (rk[sa[n - 1]] < n - 1)
        {
            tmp.clear();
            for (int i = 0; i < k; i++)
            {
                tmp.push_back(n - k + i);
            }
            for (auto i : sa)
            {
                if (i >= k)
                    tmp.push_back(i - k);
            }
            ranges::fill(cnt, 0);
            for (int i = 0; i < n; i++)
                cnt[rk[i]]++;
            for (int i = 1; i < n; i++)
                cnt[i] += cnt[i - 1];
            for (int i = n - 1; i >= 0; i--)
            {
                sa[--cnt[rk[tmp[i]]]] = tmp[i];
            }
            swap(rk, tmp);
            rk[sa[0]] = 0;
            for (int i = 1; i < n; i++)
            {
                rk[sa[i]] = rk[sa[i - 1]] + (tmp[sa[i - 1]] < tmp[sa[i]] || sa[i - 1] + k == n || tmp[sa[i - 1] + k] < tmp[sa[i] + k]);
            }
            k <<= 1;
        }
        for (int i = 0, j = 0; i < n; i++)
        {
            if (rk[i] == 0)
                j = 0;
            else
            {
                for (j -= j > 0; i + j < n && sa[rk[i] - 1] + j < n && s[i + j] == s[sa[rk[i] - 1] + j];)
                {
                    j++;
                }
                lc[rk[i] - 1] = j;
            }
        }
    }
};
```
