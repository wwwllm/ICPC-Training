# 并查集

## 模块名称

并查集

## 来源

## 适用场景

动态合并集合、判断连通性、Kruskal 最小生成树。

## 核心思想

用父指针表示集合代表元，路径压缩和按大小合并降低树高。

## 实现
 
### 代码

```cpp
struct DSU
{
    vector<int> f, siz;
    int cnt;

    DSU() {}
    DSU(int n) { init(n); }

    void init(int n)
    {
        f.resize(n);
        iota(f.begin(), f.end(), 0);
        siz.assign(n, 1);
        cnt = n;
    }

    int find(int x)
    {
        return x==f[x]?f[x]:f[x]=find(f[x]);
    }

    bool merge(int x, int y)
    {
        x = find(x);
        y = find(y);
        if (x == y)
            return 0;
        siz[x] += siz[y];
        cnt--;
        f[y] = x;
        return 1;
    }

    int esize(int x)
    {
        return siz[find(x)];
    }

    int count()
    {
        return cnt;
    }
};
```

## 复杂度

均摊近似 O(1)，空间 O(n)。

## 常见错误

- 初始化范围要覆盖所有编号。
- 合并前必须 find。
- 维护 size 时只能在根节点维护。
