# 线段树套线段树

## 模块名称

线段树套线段树

## 来源

- 数据结构/线段树套线段树.md

## 适用场景

区间加、区间查询、单点修改、动态维护聚合信息。适合题面出现“区间”“修改”“查询”“最值/和”等关键词。

## 核心思想

把整体区间递归拆成若干线段节点，每个节点保存可合并的信息；懒标记表示对子区间暂缓执行的修改。

# 线段树套线段树

## 定义

二维线段树在横坐标的每个线段树结点维护一棵纵坐标线段树，适合静态、稠密矩阵的单点修改与矩形求和。以下实现采用 $0$ 下标和左闭右开区间 `[x1, x2) × [y1, y2)`，支持初始矩阵建树、单点加、单点赋值和矩形和查询。

## 实现

外层结点覆盖一个横坐标区间，内层树维护该区间内各纵坐标区间的元素和。一次单点修改会更新所有经过的外层结点及其内层树；矩形查询将横坐标区间拆成若干外层结点，再在对应内层树中查询纵坐标区间。

### 代码

```cpp
#include <cassert>
#include <vector>

using std::vector;

struct SegTree2D {
    int n, m;
    vector<vector<long long>> tree, value;

    SegTree2D(int n, int m) {
        init(n, m);
    }

    explicit SegTree2D(const vector<vector<long long>> &a) {
        assert(!a.empty() && !a[0].empty());
        init(static_cast<int>(a.size()), static_cast<int>(a[0].size()));
        for (const auto &row : a) {
            assert(static_cast<int>(row.size()) == m);
        }
        value = a;
        build_x(1, 0, n);
    }

    void init(int _n, int _m) {
        assert(_n > 0 && _m > 0);
        n = _n;
        m = _m;
        tree.assign(4 * n, vector<long long>(4 * m));
        value.assign(n, vector<long long>(m));
    }

    void build_y(int vx, int lx, int rx, int vy, int ly, int ry) {
        if (ly + 1 == ry) {
            if (lx + 1 == rx) {
                tree[vx][vy] = value[lx][ly];
            } else {
                tree[vx][vy] = tree[vx << 1][vy] + tree[vx << 1 | 1][vy];
            }
            return;
        }
        int mid = (ly + ry) >> 1;
        build_y(vx, lx, rx, vy << 1, ly, mid);
        build_y(vx, lx, rx, vy << 1 | 1, mid, ry);
        tree[vx][vy] = tree[vx][vy << 1] + tree[vx][vy << 1 | 1];
    }

    void build_x(int vx, int lx, int rx) {
        if (lx + 1 != rx) {
            int mid = (lx + rx) >> 1;
            build_x(vx << 1, lx, mid);
            build_x(vx << 1 | 1, mid, rx);
        }
        build_y(vx, lx, rx, 1, 0, m);
    }

    void add_y(int vx, int vy, int ly, int ry, int y, long long delta) {
        tree[vx][vy] += delta;
        if (ly + 1 == ry) {
            return;
        }
        int mid = (ly + ry) >> 1;
        if (y < mid) {
            add_y(vx, vy << 1, ly, mid, y, delta);
        } else {
            add_y(vx, vy << 1 | 1, mid, ry, y, delta);
        }
    }

    void add_x(int vx, int lx, int rx, int x, int y, long long delta) {
        add_y(vx, 1, 0, m, y, delta);
        if (lx + 1 == rx) {
            return;
        }
        int mid = (lx + rx) >> 1;
        if (x < mid) {
            add_x(vx << 1, lx, mid, x, y, delta);
        } else {
            add_x(vx << 1 | 1, mid, rx, x, y, delta);
        }
    }

    void point_add(int x, int y, long long delta) {
        assert(0 <= x && x < n && 0 <= y && y < m);
        value[x][y] += delta;
        add_x(1, 0, n, x, y, delta);
    }

    void point_set(int x, int y, long long v) {
        assert(0 <= x && x < n && 0 <= y && y < m);
        point_add(x, y, v - value[x][y]);
    }

    long long query_y(int vx, int vy, int ly, int ry, int y1, int y2) const {
        if (y1 <= ly && ry <= y2) {
            return tree[vx][vy];
        }
        int mid = (ly + ry) >> 1;
        long long res = 0;
        if (y1 < mid) {
            res += query_y(vx, vy << 1, ly, mid, y1, y2);
        }
        if (y2 > mid) {
            res += query_y(vx, vy << 1 | 1, mid, ry, y1, y2);
        }
        return res;
    }

    long long query_x(int vx, int lx, int rx, int x1, int x2, int y1, int y2) const {
        if (x1 <= lx && rx <= x2) {
            return query_y(vx, 1, 0, m, y1, y2);
        }
        int mid = (lx + rx) >> 1;
        long long res = 0;
        if (x1 < mid) {
            res += query_x(vx << 1, lx, mid, x1, x2, y1, y2);
        }
        if (x2 > mid) {
            res += query_x(vx << 1 | 1, mid, rx, x1, x2, y1, y2);
        }
        return res;
    }

    long long rect_sum(int x1, int x2, int y1, int y2) const {
        assert(0 <= x1 && x1 <= x2 && x2 <= n);
        assert(0 <= y1 && y1 <= y2 && y2 <= m);
        if (x1 == x2 || y1 == y2) {
            return 0;
        }
        return query_x(1, 0, n, x1, x2, y1, y2);
    }
};
```

### 复杂度

设矩阵大小为 $n \times m$。建树时间为 $O(nm)$；单点加、单点赋值和矩形求和均为 $O(\log n\log m)$；空间复杂度为 $O(nm)$，常数较大。

### 易错点

- 该模板不支持矩形加；若需要二维区间修改，应改用二维树状数组、分治或带懒标记的二维线段树。
- `long long` 必须能容纳整个矩形和；若元素和可能溢出，需要改为 `__int128`。
- 稀疏坐标或坐标范围很大时，先离散化，或改用动态开点的嵌套线段树。

## 复杂度

建树 O(n)，单次查询/修改 O(log n)，空间 O(n)。

## 常见错误

- `mid = l + r >> 1` 建议写成 `(l + r) >> 1`，避免读代码时误判优先级。
- 区间统一使用 `[l, r)` 或 `[l, r]`，不要混用。
- 下放懒标记前要保证当前节点确实有标记。
