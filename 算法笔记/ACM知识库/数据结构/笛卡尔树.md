# 笛卡尔树

## 定义

笛卡尔树是同时满足二叉搜索树性质和堆性质的二叉树：结点按下标中序排列，权值默认满足小根堆性质。下标采用 0 下标；建树的时间复杂度为 $O(n)$，空间复杂度为 $O(n)$。

## 实现

单调栈维护当前最右链，栈中结点的权值单调不降。插入结点 `i` 时，弹出所有权值大于 `a[i]` 的结点：最后弹出的结点成为 `i` 的左儿子，剩余栈顶成为 `i` 的父亲，`i` 同时成为该栈顶的右儿子。每个结点至多入栈、出栈一次；权值相等时不弹栈，因此下标较小的结点优先作为祖先。

### 代码

```cpp
#include <functional>
#include <vector>

using namespace std;

struct CartesianTree
{
    int n, root;
    vector<int> lc, rc, fa;

    CartesianTree() : n(0), root(-1) {}

    template <class T, class Compare = less<T>>
    CartesianTree(const vector<T> &a, Compare comp = Compare())
    {
        init(a, comp);
    }

    template <class T, class Compare = less<T>>
    void init(const vector<T> &a, Compare comp = Compare())
    {
        n = static_cast<int>(a.size());
        root = -1;
        lc.assign(n, -1);
        rc.assign(n, -1);
        fa.assign(n, -1);

        vector<int> stk;
        stk.reserve(n);
        for (int i = 0; i < n; i++)
        {
            int last = -1;
            while (!stk.empty() && comp(a[i], a[stk.back()]))
            {
                last = stk.back();
                stk.pop_back();
            }
            if (!stk.empty())
            {
                rc[stk.back()] = i;
                fa[i] = stk.back();
            }
            if (last != -1)
            {
                lc[i] = last;
                fa[last] = i;
            }
            stk.push_back(i);
        }
        if (!stk.empty())
            root = stk.front();
    }
};
```

默认比较器 `less<T>` 建立小根笛卡尔树；传入 `greater<T>` 可建立大根笛卡尔树。空数组的 `root` 为 `-1`，不存在的父结点或儿子也用 `-1` 表示。

## 常见错误

- 确认下标从 0 还是 1 开始。
- 确认数组大小、INF、取模和 long long。
- 提交前用最小样例、边界样例和随机数据各测一次。
