# 学习路径建议

## 初学顺序

1. 基础语法与 [[ACM综合模板]]
2. [[并查集]]、[[线段树]]、[[01背包问题]]、[[完全背包问题]]
3. [[Dijkstra 算法]]、[[最小生成树]]、[[LCA]]
4. [[KMP算法]]、[[字符串哈希]]、[[Trie树]]

## 提升顺序

1. [[主席树]]、[[权值线段树]]、[[线段树分治]]
2. [[强连通分量]]、[[点双连通分量]]、[[Dinic]]、[[费用流]]
3. [[AC自动机]]、[[后缀自动机]]、[[Manacher]]
4. [[快速傅里叶变换（FFT）]]、[[快速数论变换（NTT）]]、[[普通生成函数]]

## 比赛前速刷顺序

1. 图论：[[Dijkstra 算法]]、[[SPFA算法]]、[[最小生成树]]、[[LCA]]、[[Dinic]]
2. 数据结构：[[线段树]]、[[并查集]]、[[主席树]]、[[莫队]]
3. 字符串：[[KMP算法]]、[[字符串哈希]]、[[AC自动机]]
4. 数学与工具：[[矩阵快速幂]]、[[快速数论变换（NTT）]]、[[int128类定义]]、[[随机]]
