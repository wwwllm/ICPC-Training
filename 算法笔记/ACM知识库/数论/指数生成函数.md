# 指数生成函数 (EGF) 与有标号计数

## 定义

指数生成函数（Exponential Generating Function）主要用于解决**有标号计数**问题。将序列 $a_0,a_1,a_2,\dots$ 映射为形式幂级数

$$
A(x)=\sum_{n=0}^{\infty}a_n\frac{x^n}{n!},
$$

其中 $a_n$ 表示在 $n$ 个不同标号上构造目标结构的方案数。

**核心算子：有标号乘积**

若 $C(x)=A(x)B(x)$，则先从 $n$ 个标号中选择 $k$ 个交给第一类结构，再用剩余标号构造第二类结构，因此

$$
c_n=\sum_{k=0}^{n}\binom{n}{k}a_k b_{n-k}.
$$

若 $A(0)=0$，由若干个 $\mathcal A$ 对象组成的无序集合对应

$$
\operatorname{SET}(\mathcal A)\longleftrightarrow \exp(A(x)).
$$

常用的标号序列与标号环构造分别对应 $1/(1-A(x))$ 与 $\log(1/(1-A(x)))$。

## 实现

将 EGF 系数 $a_i$ 除以 $i!$ 后即可使用普通多项式卷积，最后再将第 $i$ 项乘以 $i!$。下面给出 $O(NM)$ 的通用实现；数组使用 `0` 下标，`a[i]` 存储计数 $a_i$ 而非 $a_i/i!$。`T` 需要支持四则运算，且最高次数的阶乘必须可逆；在质数模数下通常要求最高次数小于模数。

### 代码

```cpp
#include <cassert>
#include <vector>

template<class T>
struct ExponentialGeneratingFunction {
    int n;
    std::vector<T> fac, ifac;

    explicit ExponentialGeneratingFunction(int n)
        : n(n), fac(n + 1), ifac(n + 1) {
        fac[0] = T(1);
        for (int i = 1; i <= n; i++) {
            fac[i] = fac[i - 1] * T(i);
        }
        ifac[n] = T(1) / fac[n];
        for (int i = n; i >= 1; i--) {
            ifac[i - 1] = ifac[i] * T(i);
        }
    }

    std::vector<T> multiply(const std::vector<T>& a,
                            const std::vector<T>& b) const {
        if (a.empty() || b.empty()) {
            return {};
        }
        int degree = static_cast<int>(a.size() + b.size()) - 2;
        assert(degree <= n);

        std::vector<T> pa(a.size()), pb(b.size());
        for (int i = 0; i < static_cast<int>(a.size()); i++) {
            pa[i] = a[i] * ifac[i];
        }
        for (int i = 0; i < static_cast<int>(b.size()); i++) {
            pb[i] = b[i] * ifac[i];
        }

        std::vector<T> c(degree + 1);
        for (int i = 0; i < static_cast<int>(a.size()); i++) {
            for (int j = 0; j < static_cast<int>(b.size()); j++) {
                c[i + j] += pa[i] * pb[j];
            }
        }
        for (int i = 0; i <= degree; i++) {
            c[i] *= fac[i];
        }
        return c;
    }
};
```

若两个序列的最高次数分别为 $N$ 和 $M$，时间复杂度为 $O(NM)$，空间复杂度为 $O(N+M)$；将代码中的普通卷积替换为 NTT 后可降至 $O((N+M)\log(N+M))$。
