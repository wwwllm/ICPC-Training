# 狄利克雷卷积

## 定义

两个算术函数 $f,g$ 的狄利克雷卷积定义为

$$
(f*g)(n)=\sum_{d\mid n}f(d)g\left(\frac nd\right).
$$

狄利克雷卷积满足交换律、结合律和分配律，单位元为 $\varepsilon(n)=[n=1]$。若 $f(1)$ 在当前数域中可逆，则 $f$ 存在唯一卷积逆元；两个积性函数的卷积仍是积性函数。

常用恒等式为

$$
\mathbf{1}*\mu=\varepsilon,\qquad
\mathbf{1}*\varphi=\operatorname{id},
$$

其中 $\mathbf{1}(n)=1$，$\operatorname{id}(n)=n$。

## 实现

数组使用 `1` 下标，`f[0]`、`g[0]` 无意义。枚举因子 $d$ 和另一因子 $k$，将贡献累加到 $d k$；求逆时按下标递增维护已知项对后续倍数的贡献。`T` 需要支持四则运算，调用 `dirichlet_inverse` 时还要求 `f[1]` 可逆。

### 代码

```cpp
#include <cassert>
#include <vector>

template<class T>
std::vector<T> dirichlet_convolution(const std::vector<T>& f,
                                     const std::vector<T>& g,
                                     int n) {
    assert(static_cast<int>(f.size()) > n);
    assert(static_cast<int>(g.size()) > n);
    std::vector<T> h(n + 1);
    for (int d = 1; d <= n; d++) {
        for (int k = 1; d * k <= n; k++) {
            h[d * k] += f[d] * g[k];
        }
    }
    return h;
}

template<class T>
std::vector<T> dirichlet_inverse(const std::vector<T>& f) {
    int n = static_cast<int>(f.size()) - 1;
    assert(n >= 1);

    std::vector<T> g(n + 1), sum(n + 1);
    T inv_f1 = T(1) / f[1];
    g[1] = inv_f1;

    for (int k = 1; k <= n; k++) {
        if (k > 1) {
            g[k] = -inv_f1 * sum[k];
        }
        for (int d = 2; d * k <= n; d++) {
            sum[d * k] += f[d] * g[k];
        }
    }
    return g;
}
```

计算 $1\sim N$ 的卷积或卷积逆均需 $O(N\log N)$ 时间和 $O(N)$ 空间。
