# 莫比乌斯反演

## 定义

莫比乌斯反演用于从整除偏序上的前缀和恢复原函数。莫比乌斯函数满足 $\sum_{d\mid n}\mu(d)=[n=1]$，其中

$$
\mu(n)=
\begin{cases}
1,&n=1,\\
0,&n\text{ 含有平方因子},\\
(-1)^k,&n\text{ 是 }k\text{ 个不同质数的乘积}.
\end{cases}
$$

常用的两种反演形式为

$$
F(n)=\sum_{d\mid n}f(d)
\iff
f(n)=\sum_{d\mid n}\mu(d)F\left(\frac nd\right),
$$

以及

$$
F(n)=\sum_{n\mid d}f(d)
\iff
f(n)=\sum_{n\mid d}\mu\left(\frac dn\right)F(d).
$$

## 常见数论函数的反演形式

记 $\varepsilon(n)=[n=1]$，$\varphi$ 为欧拉函数，$\sigma_k(n)=\sum_{d\mid n}d^k$。常用恒等式如下：

- 莫比乌斯函数是常函数 $1$ 在狄利克雷卷积下的逆元：
  $$
  \sum_{d\mid n}\mu(d)=\varepsilon(n).
  $$
- 欧拉函数：
  $$
  \sum_{d\mid n}\varphi(d)=n
  \iff
  \varphi(n)=\sum_{d\mid n}\mu(d)\frac nd
  =n\sum_{d\mid n}\frac{\mu(d)}d.
  $$
- 约数幂和函数，其中 $k$ 为非负整数：
  $$
  \sigma_k(n)=\sum_{d\mid n}d^k
  \iff
  n^k=\sum_{d\mid n}\mu(d)\sigma_k\left(\frac nd\right).
  $$
- 互质指示函数：
  $$
  [\gcd(a,b)=1]=\sum_{d\mid\gcd(a,b)}\mu(d).
  $$

## 实现

线性筛维护每个数的最小质因子转移：若质数 $p\mid i$，则 $p^2\mid ip$，令 $\mu(ip)=0$ 并停止枚举；否则令 $\mu(ip)=-\mu(i)$。返回数组使用 `1` 下标，要求 $N\ge 0$，其中 `mu[0]` 无意义。

### 代码

```cpp
const int N = 1e7;
vector<int> vis(N + 1), prime, mu(N + 1);
void init()
{
    mu[1] = 1;
    for (int i = 2; i <= N; i++)
    {
        if (!vis[i])
        {
            prime.push_back(i);
            mu[i] = -1;
        }
        for (auto p : prime)
        {
            if (i * p > N)
                break;
            vis[i * p] = 1;
            if (i % p == 0)
            {
                mu[i * p] = 0;
                break;
            }
            mu[i * p] = mu[i] * mu[p];
        }
    }
}
```

预处理 $1\sim N$ 的莫比乌斯函数时间复杂度为 $O(N)$，空间复杂度为 $O(N)$。
