# 狄利克雷生成函数 (DGF) 与算术函数

## 定义

狄利克雷生成函数（Dirichlet Generating Function）主要用于研究定义在正整数上的算术函数。将序列 $a_1,a_2,a_3,\dots$ 映射为形式级数

$$
A(s)=\sum_{n=1}^{\infty}\frac{a_n}{n^s}.
$$

在组合恒等式中通常只关心形式系数；若把它视为复函数，则还需单独判断级数的收敛域。

**核心算子：狄利克雷卷积**

若 $A(s)$ 与 $B(s)$ 的系数分别为 $a_n$ 与 $b_n$，则

$$
A(s)B(s)=\sum_{n=1}^{\infty}\frac{1}{n^s}
\sum_{d\mid n}a_d b_{n/d}.
$$

因此，狄利克雷生成函数的乘法对应系数序列的狄利克雷卷积。若 $a$ 是积性函数，还可以按质数分解为欧拉乘积

$$
A(s)=\prod_p\left(\sum_{k=0}^{\infty}\frac{a_{p^k}}{p^{ks}}\right).
$$

常用对应关系为

$$
\mathbf{1}\longleftrightarrow\zeta(s),\qquad
\varepsilon\longleftrightarrow 1,\qquad
\mu\longleftrightarrow\frac{1}{\zeta(s)},\qquad
\operatorname{id}_k\longleftrightarrow\zeta(s-k),
$$

其中 $\mathbf{1}(n)=1$，$\varepsilon(n)=[n=1]$，$\operatorname{id}_k(n)=n^k$。

## 实现

竞赛中通常不直接计算无穷级数，而是维护 $1\sim N$ 的系数。下面的组件将两个截断狄利克雷级数相乘，数组使用 `1` 下标，`coef[0]` 无意义；`T` 需要支持默认构造、加法与乘法。

### 代码

```cpp
#include <vector>

template<class T>
struct DirichletSeries {
    int n;
    std::vector<T> coef;

    explicit DirichletSeries(int n = 0) : n(n), coef(n + 1) {}

    T& operator[](int i) {
        return coef[i];
    }

    const T& operator[](int i) const {
        return coef[i];
    }

    static DirichletSeries multiply(const DirichletSeries& a,
                                    const DirichletSeries& b,
                                    int limit) {
        DirichletSeries c(limit);
        for (int d = 1; d <= limit && d <= a.n; d++) {
            for (int k = 1; d * k <= limit && k <= b.n; k++) {
                c[d * k] += a[d] * b[k];
            }
        }
        return c;
    }
};
```

计算前 $N$ 项乘积的时间复杂度为 $O(N\log N)$，空间复杂度为 $O(N)$。
