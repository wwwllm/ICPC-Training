## 定义

与[[01背包问题]]不同的是，每一种物品的数量都是无限的。

## 实现

我们设DP状态为$dp[i][j]$在只能在前$i$个的物品中选择的情况下，容量为$j$的背包的最大价值。
我们考虑一个朴素的做法：$$ dp[i][j] = \operatorname*{m a x}_{k=0}^{+\infty} (dp[i][j-k\times w_i]+ v_i \times k) $$ 
我们考虑一个简单的优化，对于$dp[i][j]$可以通过$dp[i][j-w_i]$来转移，因此我们可以得到：$$dp[i][j]=max(dp[i][j-1],dp[i][j-w_i]+v_i)$$
同样我们也可以用滚动数组去优化空间复杂度
## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

signed main()
{
    int n, v;
    cin >> n >> v;
    vector<array<int, 2>> a(n + 1);
    for (int i = 1; i <= n; i++)
        cin >> a[i][0] >> a[i][1];
    vector<int> dp(v + 1);
    for (int i = 1; i <= n; i++)
    {
        auto [cost, val] = a[i];
        for (int j = cost; j <= v; j++)
            dp[j] = max(dp[j], dp[j - cost] + val);
    }
    cout << dp[v] << '\n';
    return 0;
}
```
