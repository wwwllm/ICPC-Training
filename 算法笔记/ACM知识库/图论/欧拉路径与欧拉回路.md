# 欧拉路径与欧拉回路

## 定义

欧拉路径经过图中每条边恰好一次，欧拉回路还要求起点与终点相同。判断时忽略孤立点，并要求所有非孤立点在对应的无向图中连通。

### 存在条件

- **无向图**：奇度点数量为 $0$ 或 $2$ 时存在欧拉路径；为 $0$ 时存在欧拉回路，为 $2$ 时路径必须从一个奇度点走到另一个奇度点。
- **有向图**：所有点入度等于出度时存在欧拉回路；或恰有一个点满足 $out=in+1$、一个点满足 $in=out+1$，其余点入度等于出度时存在欧拉路径。

## 实现

使用 Hierholzer 算法不断沿未使用边前进，无边可走时将当前点加入答案，最后反转序列。时间复杂度为 $O(n+m)$，空间复杂度为 $O(n+m)$，其中 $n$ 为点数，$m$ 为边数。

模板点编号为 $0\sim n-1$，支持重边和自环。`run()` 返回长度为 $m+1$ 的点序列；不存在欧拉路径时返回空数组，无边图返回 `{0}`。

### 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct euler
{
    vector<vector<int>> adj;
    vector<int> ind, out;
    vector<int> cur;
    int n;
    euler(int n) : n(n), adj(n), ind(n), out(n) {}
    void add(int u, int v)
    {
        adj[u].push_back(v);
        out[u]++, ind[v]++;
    };

    vector<int> work()
    {
        vector<int> res;
        int s = -1, t = -1;
        for (int i = 0; i < n; i++)
        {
            if (out[i] == ind[i] + 1)
            {
                if (s != -1)
                    return res;
                s = i;
            }
            else if (ind[i] == out[i] + 1)
            {
                if (t != -1)
                    return res;
                t = i;
            }
            else if (out[i] != ind[i])
                return res;
        }
        if (s == -1)
        {
            for (int i = 0; i < n; i++)
            {
                if (out[i] != 0)
                {
                    s = i;
                    break;
                }
            }
        }
        for (int i = 0; i < n; i++)
        {
            ranges::sort(adj[i]);
        }
        if (s == -1)
            return res;
        cur.assign(n, 0);
        auto dfs = [&](auto &&self, int u) -> void
        {
            for (int &i = cur[u]; i < adj[u].size();)
            {
                auto v = adj[u][i++];
                self(self, v);
            }
            res.push_back(u);
        };
        dfs(dfs, s);
        ranges::reverse(res);
        return res;
    }
};
```
