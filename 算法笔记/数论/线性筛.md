# 线性筛（欧拉筛）

## 定义

线性筛按每个合数的最小质因子唯一生成该合数，可在 $O(N)$ 时间内筛出 $1\sim N$ 的全部质数。利用相同的转移还能同时预处理最小质因子、欧拉函数 $\varphi$ 和莫比乌斯函数 $\mu$。

## 实现

对每个 $i$ 只枚举满足 $p\le \operatorname{minp}(i)$ 的质数 $p$。此时 $p$ 是 $ip$ 的最小质因子，因此每个合数只会被筛到一次：

- 若 $p=\operatorname{minp}(i)$，则 $p\mid i$，有 $\varphi(ip)=p\varphi(i)$、$\mu(ip)=0$。
- 若 $p<\operatorname{minp}(i)$，则 $\gcd(i,p)=1$，有 $\varphi(ip)=(p-1)\varphi(i)$、$\mu(ip)=-\mu(i)$。

数组使用 `1` 下标，`minp[0]`、`phi[0]` 和 `mu[0]` 无意义。`factorize(x)` 要求 $1\le x\le N$；`x=1` 时返回空分解。

### 代码

```cpp
const int N = 1e7;
vector<int> vis(N + 1), prime;
void init()
{
    for (int i = 2; i <= N; i++)
    {
        if (!vis[i])
        {
            prime.push_back(i);
        }
        for (auto p : prime)
        {
            if (i * p > N)
                break;
            vis[i * p] = 1;
            if (i % p == 0)
	            break;
        }
    }
}
```

预处理时间复杂度为 $O(N)$，空间复杂度为 $O(N)$；单次分解 $x$ 的时间复杂度为 $O(\log x)$，返回结果按质因子从小到大排列。
