# 中国剩余定理（CRT）

## 定义

给定同余方程组 $x\equiv r_i\pmod{m_i}$，当所有模数 $m_i$ 为正且两两互质时，方程组在模 $M=\prod m_i$ 意义下有唯一解。模板返回区间 $[0,M)$ 内的最小非负解，要求 $M$ 能放入 `long long`。

## 实现

令 $M_i=M/m_i$，用扩展欧几里得算法求出 $M_i$ 在模 $m_i$ 下的逆元 $t_i$。答案为

$$
x\equiv\sum_{i=0}^{n-1}r_iM_it_i\pmod M.
$$

输入数组使用 `0` 下标，`r` 与 `m` 长度必须相同，余数允许为负；空同余方程组返回 `0`。

### 代码

```cpp
long long exgcd(long long a, long long b, long long &x, long long &y)
{
    if (!b)
    {
        x = 1, y = 0;
        return a;
    }
    long long x1, y1;
    long long g = exgcd(b, a % b, x1, y1);
    x = y1;
    y = x1 - a / b * y1;
    return g; // ax + by = gcd(a, b)
}
bool merge_crt(long long &a1, long long &m1, long long a2, long long m2)
{
    long long x, y;
    long long g = exgcd(m1, m2, x, y);
    long long c = a2 - a1;
    if (c % g)
        return false; // 差值不能被 gcd 整除，无解

    long long mod = m2 / g;
    x = (__int128)x * (c / g) % mod;
    a1 += x * m1;
    m1 *= mod; // 新模数为 lcm(m1, m2)
    a1 = (a1 % m1 + m1) % m1;
    return true;
}

// equations: {余数, 模数}
array<int,2> excrt(const vector<array<int,2>> &equations)
{
    long long a = equations[0][0];
    long long m = equations[0][1];
    for (int i = 1; i < (int)equations.size(); i++)
    {
        if (!merge_crt(a, m, equations[i][0], equations[i][1]))
            return {-1, -1};
    }
    return {a, m}; // x = a (mod m)
}
```

设方程数量为 $n$，时间复杂度为 $O(n\log M)$，递归栈空间复杂度为 $O(\log M)$。`__int128` 只保护中间乘法，调用者仍需保证 $M$ 不会溢出 `long long`；模数不互质时应改用扩展中国剩余定理。
