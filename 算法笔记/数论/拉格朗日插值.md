# 拉格朗日插值

## 定义

已知 $n$ 个横坐标两两不同的点 $(x_i, y_i)$，可唯一确定一个次数小于 $n$ 的多项式。下面在质数模数 `MOD` 下计算该多项式在 `k` 处的值；要求所有 `x_i` 模 `MOD` 后互不相同。

时间复杂度为 $O(n^2+n\log MOD)$，其中 $n$ 为插值点个数；空间复杂度为 $O(n)$。

## 实现

根据

$$
f(k)=\sum_{i=0}^{n-1}y_i\prod_{j\ne i}\frac{k-x_j}{x_i-x_j}
$$

逐项计算分子和分母。`x`、`y` 均为 0 下标数组；输入值可以是任意整数，函数会将其规范到模 `MOD` 的范围内。

### 代码

```cpp
#include <cassert>
#include <vector>

using i64 = long long;

constexpr i64 MOD = 998244353;

i64 mod_pow(i64 a, i64 e) {
    i64 res = 1;
    while (e > 0) {
        if (e & 1) res = res * a % MOD;
        a = a * a % MOD;
        e >>= 1;
    }
    return res;
}

i64 norm(i64 x) {
    x %= MOD;
    return x < 0 ? x + MOD : x;
}

// 返回经过 (x[i], y[i]) 的多项式在 k 处的值。
i64 lagrange(const std::vector<i64>& x, const std::vector<i64>& y, i64 k) {
    int n = x.size();
    assert(n > 0 && y.size() == x.size());

    std::vector<i64> xs(n), ys(n);
    for (int i = 0; i < n; i++) {
        xs[i] = norm(x[i]);
        ys[i] = norm(y[i]);
    }
    k = norm(k);

    for (int i = 0; i < n; i++) {
        if (xs[i] == k) return ys[i];
    }

    i64 ans = 0;
    for (int i = 0; i < n; i++) {
        i64 num = 1, den = 1;
        for (int j = 0; j < n; j++) {
            if (i == j) continue;
            num = num * norm(k - xs[j]) % MOD;
            den = den * norm(xs[i] - xs[j]) % MOD;
        }
        assert(den != 0);  // 保证所有横坐标模 MOD 后互不相同。
        ans = (ans + ys[i] * num % MOD * mod_pow(den, MOD - 2)) % MOD;
    }
    return ans;
}
```
