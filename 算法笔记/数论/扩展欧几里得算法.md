# 扩展欧几里得算法（exgcd）

## 定义

扩展欧几里得算法用于求整数 $a,b$ 的最大公约数 $g$，并构造一组整数 $x,y$，使得 $ax+by=g$。模板要求 $a,b$ 非负且不同时为 $0$，时间复杂度为 $O(\log \min(a,b))$。

## 实现

递归求出 $bx_1+(a\bmod b)y_1=g$。由 $a\bmod b=a-\lfloor a/b\rfloor b$ 可得 $x=y_1$、$y=x_1-\lfloor a/b\rfloor y_1$；当 $b=0$ 时取 $x=1,y=0$。

### 代码

```cpp
long long exgcd(long long a, long long b, long long &x, long long &y) {
    if (b == 0) {
        x = 1;
        y = 0;
        return a;
    }
    long long x1, y1;
    long long g = exgcd(b, a % b, x1, y1);
    x = y1;
    y = x1 - a / b * y1;
    return g;
}
```

递归栈空间复杂度为 $O(\log \min(a,b))$。若输入或中间乘积可能超出 `long long`，需要将系数和运算过程改为 `__int128`。
