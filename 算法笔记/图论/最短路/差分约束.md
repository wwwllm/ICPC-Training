## 定义

**差分约束系统**是一种特殊的 $n$ 元一次不等式组，它包含 $n$ 个变量 $x_1,x_2,x_3,\ldots,x_n$ 以及m个约束条件，每个约束条件是由两个变量做差构成的，$eg: x_i-x_j\le c_k$ *（并且 $c_k$ 是常数）*，我们需要找到一组解使得约束条件成立，否则判断出无解。

在差分约束系统中每个约束条件 $x_i-x_j\le c_k$ 都可以变形为 $x_i \le c_k+x_j$ ，这与单源最短路中的三角不等式 $dis[y] \le dis[x]+z$ 非常相似。因此，我们可以把变量 $x_i$ 看作图中的一个节点，而对于每一个约束条件 $x_i-x_j\le c_k$ 看作是一条从 $x_j$ 向$x_i$ 连一条长度为 $c_k$ 的有向边。

## 实现

设$dis[0]=0$ 并向每个点连一条长度为$0$的边（添加一个源点0，保证每个点都会被遍历到），跑单元最短路，如果图中存在负环，则该差分约束系统无解，否则，$x_i=dis[i]$ 为差分系统的一组解。

## 代码

```cpp
#include <bits/stdc++.h>
#define pb push_back
#define int long long
using namespace std;

  
// https://www.luogu.com.cn/problem/P1993
const int inf = 1e18;
void solve()
{
    int n, m;
    cin >> n >> m;
    vector<vector<array<int, 2>>> g(n + 1);
    for (int i = 1; i <= m; i++)
    {
        int op;
        cin >> op;
        if (op == 1)
        {
            int a, b, c;
            cin >> a >> b >> c;
            g[a].pb({b, -c});
        }
        else if (op == 2)
        {
            int a, b, c;
            cin >> a >> b >> c;
            g[b].pb({a, c});
        }
        else
        {
            int a, b;
            cin >> a >> b;
            g[a].pb({b, 0});
            g[b].pb({a, 0});
        }
    }
    for (int i = 1; i <= n; i++)
        g[0].pb({i, 0});
    vector<int> dis(n + 1, inf);
    auto spfa = [&]() -> bool
    {
        vector<int> vis(n + 1), cnt(n + 1);
        queue<int> q;
        dis[0] = 0;
        q.push(0);
        vis[0] = 1;
        while (q.size())
        {
            auto u = q.front();
            q.pop();
            vis[u] = 0;
            for (auto [v, w] : g[u])
            {
                if (dis[v] > dis[u] + w)
                {
                    cnt[v] = cnt[u] + 1;
                    dis[v] = dis[u] + w;
                    if (cnt[v] >= n)
                        return 0;
                    if (!vis[v])
                        q.push(v), vis[v] = 1;
                }
            }
        }
        return 1;
    };
    bool ok = spfa();
    cout << (ok ? "Yes\n" : "No\n");
}
signed main()
{
    ios::sync_with_stdio(0), cin.tie(0), cout.tie(0);
    int t = 1;
    // cin >> t;
    while (t--)
        solve();
    return 0;
}
```
