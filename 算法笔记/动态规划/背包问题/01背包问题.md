## 定义

给你$n$个物品，其中第$i$个物品的重量和价值为$w_i,v_i$ ,已经背包的总容量$W$。
求背包最多可以容纳的总价值。
时间复杂度为$O(N^2)$ 

## 实现

我们设DP状态为$dp[i][j]$在只能在前$i$个的物品中选择的情况下，容量为$j$的背包的最大价值。我们可以得到一些状态转移方程：$$dp[i][j]=max(dp[i-1][j],dp[i-1][j-w_i]+v_i)$$ 用滚动数组优化后的方程为：$$dp[j]=max(dp[j],dp[j-w_i]+v_i)$$ 
## 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

signed main()
{
    int n, v;
    cin >> n >> v;
    vector<array<int, 2>> a(n + 1);
    for (int i = 1; i <= n; i++)
        cin >> a[i][0] >> a[i][1];
    vector<int> dp(v + 1);
    for (int i = 1; i <= n; i++)
    {
        auto [cost, val] = a[i];
        for (int j = v; j >= cost; j--)
            dp[j] = max(dp[j], dp[j - cost] + val);
    }
    cout << dp[v] << '\n';
    return 0;
}
```
