### Problem A: Average of Averages
**时限**: 1.0s | **空间限制**: 1024MB

*“平均数的平均数并不总是真正的平均数。”*

#### 题目描述
VegiCat 刚学了线段树，想练习如何使用它。
对于正整数 $n$，他考虑序列 $a_i = i \ (1 \le i \le n)$。他决定建一棵线段树来回答该序列上的**区间平均值**查询。

在 VegiCat 的线段树中，每个节点对应一个区间 $[l, r]$ 并存储一个值 $v_{l, r}$，他本意是用该值代表该区间的平均数。根节点对应整个区间 $[1, n]$。

然而，VegiCat 误以为**父节点的区间平均数总是等于其左右两个子节点存储值的平均数**。因此，他直接将两子节点的值相加并除以 2。

建树时，VegiCat 首先调用 `Build(1, n)`。建完后，他对区间 $[L, R]$ 的查询调用 `Query(1, n, L, R)`。两个递归过程如下：

```text
procedure Build(l, r):
    if l == r then
        v[l, l] = a[l]
        return
    m = floor((l + r) / 2)
    Build(l, m)
    Build(m + 1, r)
    v[l, r] = (v[l, m] + v[m + 1, r]) / 2

procedure Query(l, r, L, R):
    if L <= l and r <= R then
        return v[l, r]
    m = floor((l + r) / 2)
    if R <= m then
        return Query(l, m, L, R)
    else if L > m then
        return Query(m + 1, r, L, R)
    x = Query(l, m, L, R)
    y = Query(m + 1, r, L, R)
    return (x + y) / 2
```

尽管 VegiCat 的算法整体上是错误的，但对某些区间它仍然能返回正确的真实平均值。
对于区间 $[L, R]$，其真实的平均值为：
$$\frac{\sum_{i=L}^R a_i}{R - L + 1}$$

更准确地说，统计满足 $1 \le L \le R \le n$ 且满足下式的区间对 $(L, R)$ 数量：
$$\text{Query}(1, n, L, R) = \frac{\sum_{i=L}^R a_i}{R - L + 1}$$

所有平均值均按精确的**有理数**计算，不进行任何四舍五入或截断。

#### 输入格式
第一行包含一个整数 $T \ (1 \le T \le 10^4)$，表示测试用例组数。
接下来 $T$ 行，每行一个整数 $n \ (1 \le n \le 10^6)$，表示序列长度。
保证所有用例的 $n$ 之和不超过 $2 \times 10^6$。

#### 输出格式
对每个测试用例，输出一行一个整数，表示使 VegiCat 查询过程恰好返回真实平均值的区间 $[L, R]$ 的个数。

#### 样例
**输入**
```text
3
1
5
14
```
**输出**
```text
1
10
35
```

### Problem B: Bouncing Particles
**时限**: 2.0s | **空间限制**: 1024MB

#### 题目描述
VegiCat 在一个 $n \times n$ 的网格上观察粒子。左下角单元格坐标为 $(1, 1)$。水平坐标自左向右递增，垂直坐标自下向上递增。每个粒子具有一个水平方向（向左或向右）和一个垂直方向（向上或向下）。

在每个时间步开始时，每个粒子按如下规则调整方向：
- 若其水平方向上的下一个单元格在网格外部，则其水平方向反转；
- 若其垂直方向上的下一个单元格在网格外部，则其垂直方向反转。

调整方向后，位于 $(x, y)$ 的粒子分裂产生两个子粒子：
- 一个位于 $(x-1, y)$（若其水平方向为左）或 $(x+1, y)$（若其水平方向为右）；
- 一个位于 $(x, y-1)$（若其垂直方向为下）或 $(x, y+1)$（若其垂直方向为上）。

两个子粒子均继承父粒子当前的水平与垂直方向，随后父粒子消失。

多个粒子可以同时占据同一个单元格（无论方向是否相同），彼此之间不发生碰撞与交互，也不改变彼此方向。

在时刻 $t=0$，单元格 $(x_0, y_0)$ 处有 4 个粒子，方向分别为：
1. 向右且向上；
2. 向左且向上；
3. 向右且向下；
4. 向左且向下。

每个时间步，所有粒子同时调整方向并按上述规则分裂。

给出 $q$ 次询问。每次询问给定整数 $A, B, C$ 及一个时刻 $t$。请计算在时刻 $t$，满足直线方程 $Ax + By + C = 0$ 且**包含至少一个粒子**的网格单元格 $(x, y)$ 的数量。

#### 输入格式
第一行包含一个整数 $T \ (1 \le T \le 10^5)$，表示测试用例组数。
每个测试用例第一行包含四个整数 $n, x_0, y_0, q \ (2 \le n \le 10^9, 1 \le x_0, y_0 \le n, 1 \le q \le 10^5)$。
接下来 $q$ 行，每行包含四个整数 $A, B, C, t \ (|A|, |B|, |C| \le 10^9, 0 \le t \le 10^9)$，保证 $A, B$ 不同时为 0。
保证所有用例的 $q$ 之和不超过 $10^5$。

#### 输出格式
对每个询问，输出一行一个整数：在时刻 $t$ 满足 $Ax + By + C = 0$ 且至少有一个粒子的格子数。

#### 样例
**输入**
```text
1
6 5 5 4
2 -1 -5 0
1 -1 0 1
11 45 14 2
1 0 -5 3
```
**输出**
```text
1
0
0
3
```

### Problem C: Counting Arrays
**时限**: 2.0s | **空间限制**: 1024MB

#### 题目描述
给定两个整数 $n$ 和 $m$。考虑满足下列条件的整数数组 $a_1, a_2, \dots, a_n$：
- $a_1 = 0$
- $0 \le a_{i+1} - a_i \le 1 \quad (1 \le i < n)$

设 $s_i = a_1 + a_2 + \dots + a_i$ 为数组 $a$ 的前缀和。
给出了 $m$ 个位置处的前缀和限制：即对于 $1 \le j \le m$，给定 $s_{p_j} = v_j$。

求满足所有限制的合法数组 $a$ 的数量，模 $998244353$。若无合法数组，输出 0。

#### 输入格式

接下来 $m$ 行，第 $j$ 行包含两个整数 $p_j, v_j \ (1 \le p_j \le n, 0 \le v_j \le 10^9)$。
输入保证 $p_j$ 严格单调递增。

#### 输出格式
对每个测试用例，输出满足条件的数组总数模 $998244353$。

#### 样例
**输入**
```text
6
1 0
3 1
3 1
3 1
2 0
4 1
4 3
5 2
1 0
5 4
5 2
2 0
5 10
```
**输出**
```text
1
1
2
2
2
0
```

### Problem D: Duel of Wrath
**时限**: 1.0s | **空间限制**: 1024MB

#### 题目描述
VegiCat 和 VegiDog 在《杀戮尖塔》中进行一场特殊决斗。VegiCat 操控观者（Watcher）A，VegiDog 操控观者 B。A 和 B 的基础攻击力分别为 $a$ 和 $b$，初始生命值分别为 $h_A$ 和 $h_B$。

每回合开始时，游戏决定两名角色的姿态（Stance）。每个角色可以处于以下两种姿态之一：
- **平静/普通（Normal）**：造成和受到的伤害不变；
- **愤怒（Wrath）**：造成和受到的伤害均翻倍。

每次攻击的基础伤害等于攻击者的基础攻击力。若攻击者处于愤怒，伤害翻倍；若防守者处于愤怒，伤害再次翻倍。
因此每回合造成的伤害如下：
- 双方面容平静：A 对 B 造成 $a$ 点伤害，B 对 A 造成 $b$ 点伤害；
- 恰有一人愤怒：A 对 B 造成 $2a$ 点伤害，B 对 A 造成 $2b$ 点伤害；
- 双方均愤怒：A 对 B 造成 $4a$ 点伤害，B 对 A 造成 $4b$ 点伤害。

每回合两人**同时**攻击一次，生命值同时扣除。即使某方生命降至 0 或以下，本回合攻击仍全部生效结算。回合结束时，生命值 $\le 0$ 的角色死亡。若有任一角色死亡，战斗立即结束；否则进入下一回合。基础攻击力不改变，生命值不可恢复。

每回合双方的姿态由游戏决定，**无法由玩家控制**（四种姿态组合每回合均可能发生）。

VegiCat **仅在 B 死亡且 A 存活时获胜**。若同归于尽，算 VegiCat 未获胜。
请判断：**无论游戏如何分配双方各回合的姿态，VegiCat 是否都必定获胜？**

#### 输入格式
第一行输入整数 $T \ (1 \le T \le 10^5)$。
接下来 $T$ 行，每行四个整数 $a, b, h_A, h_B \ (1 \le a, b, h_A, h_B \le 10^{18})$。

#### 输出格式
若 VegiCat 必胜输出 `YES`，否则输出 `NO`（大小写不敏感）。

#### 样例
**输入**
```text
5
1 1 5 1
1 1 4 1
1 1 1 1
1 1 1 5
2 3 13 2
```
**输出**
```text
YES
NO
NO
NO
YES
```

### Problem E: Enclose the Point
**时限**: 1.0s | **空间限制**: 1024MB

#### 题目描述
平面上有 $n$ 个互不相同的点 $P_1, P_2, \dots, P_n$。给出 $q$ 次询问，每次询问给定一个点 $P$。
对于每次询问，请选定若干给定的点作为顶点构造一个**简单多边形**，使得：
1. 询问点 $P$ **严格位于多边形内部**（不能在边界上）；
2. 构造的多边形**顶点数最少**。

若不存在这样的多边形，输出 `-1`。
（简单多边形：至少 3 个顶点，相邻边仅在公共端点相交，非相邻边互不相交）。

#### 输入格式
第一行包含一个整数 $T \ (1 \le T \le 2 \times 10^4)$。
每个测试用例第一行包含两个正整数 $n, q \ (3 \le n \le 10^5, 1 \le q \le 10^5)$。
接下来 $n$ 行，第 $i$ 行包含两整数 $x_i, y_i \ (-10^9 \le x_i, y_i \le 10^9)$ 表示 $P_i$ 的坐标。
接下来 $q$ 行，每行包含两整数 $x, y \ (-10^9 \le x, y \le 10^9)$ 表示询问点 $P$ 的坐标。
保证所有用例的 $\sum n \le 10^5, \sum q \le 10^5$。

#### 输出格式
对于每个询问：
- 若不存在合法多边形，输出一行一个整数 `-1`；
- 否则，第一行输出顶点数 $m$；第二行按顺时针或逆时针顺序输出 $m$ 个互不相同的顶点编号 $a_1, a_2, \dots, a_m \ (1 \le a_i \le n)$。若有多解输出任意一个。

#### 样例
**输入**
```text
2
5 1
0 4
-3 0
-3 -3
3 -3
3 0
0 0
3 1
0 4
-3 0
3 0
0 0
```
**输出**
```text
3
4 1 2
-1
```

### Problem F: First Word
**时限**: 5.0s | **空间限制**: 1024MB

#### 题目描述
VegiCat 有一个由 $n$ 个小写英文字母组成的字符串 $S$。他想构建一个词典，该词典包含 $S$ 的 $k$ 个**互不相同的非空子串**作为词汇。内容相同的子串视为同一个词（即使在 $S$ 中出现位置不同）。

设 $\pi$ 为 26 个英文字母上的任意一个置换映射。对于字符串 $u = u_1 u_2 \dots u_m$，定义 $\pi(u) = \pi(u_1)\pi(u_2)\dots\pi(u_m)$。

VegiCat 希望词典中存在一个单词 $w$，满足：**对于任何 26 个字母的置换映射 $\pi$，当对词典中所有单词应用该映射后，$\pi(w)$ 总是结果词典中字典序严格最小的单词**。

对于每个 $k = 1, 2, \dots, n$，求满足上述条件的含有 $k$ 个不同单词的词典数量，模 $998244353$。若两个词典在应用置换前包含的单词集合不同，则视为不同词典。

#### 输入格式
第一行输入整数 $T \ (1 \le T \le 10^4)$。
每个测试用例第一行输入整数 $n \ (1 \le n \le 10^5)$。
第二行输入长度为 $n$ 的小写字母字符串 $S$。
保证 $\sum n \le 10^5$。

#### 输出格式
对每个测试用例，输出一行 $n$ 个整数，第 $k$ 个整数表示大小为 $k$ 的合法词典数量模 $998244353$。

#### 样例
**输入**
```text
3
3
aab
4
ppqq
7
abcaabc
```
**输出**
```text
5 4 3
8 10 11 10
21 52 87 119 139 128 84
```

### Problem G: Graph Reconstruction
**时限**: 2.0s | **空间限制**: 1024MB

#### 题目描述
给定一个 $n \times n$ 的整数矩阵 $A = (a_{ij})$。满足：
- 当 $i = j$ 或 $i = 1$ 或 $j = 1$ 时，$a_{ij} = -1$；
- 否则，$a_{ij}$ 是非负整数。

请构造一个 $n$ 个顶点（编号 $1 \sim n$）的无向简单图 $G$。
图必须满足：对于每一对满足 $i > 1$ 且 $j > 1$ 的不同顶点 $i, j$，在图 $G$ 中**删除顶点 $i$ 和 $j$ 以及与它们相连的所有边**后，剩余的边数恰好为 $a_{ij}$。
（每对点 $(i, j)$ 是独立考虑的，即删除前图都是初始图 $G$）。

保证至少存在一个满足条件的图。若有多解输出任意一个。

#### 输入格式
第一行输入 $T \ (1 \le T \le 6 \times 10^4)$。
每个用例第一行包含整数 $n \ (4 \le n \le 10^3)$。
接下来 $n$ 行每行包含 $n$ 个整数表示矩阵 $A$。
保证 $\sum n^2 \le 1.2 \times 10^6$。

#### 输出格式
对每个测试用例输出构造图的邻接矩阵（$n$ 行，每行 $n$ 个由空格隔开的 0 或 1）。

### Problem H: Hidden Order
**时限**: 1.0s | **空间限制**: 1024MB
**题型**: 交互题（Interactive）

#### 题目描述
VegiCat 有一个隐藏的数组 $a_1, a_2, \dots, a_n$，其中每个元素的值只能是 $0, 1$ 或 $2$。
你每次可以询问两个下标 $i$ 和 $j$，交互器会告诉你是否满足 $a_i > a_j$。
你需要在最多 **$2n - 3$** 次询问内，将所有下标按元素值升序排序，即找出一个 $1 \sim n$ 的排列 $p_1, p_2, \dots, p_n$，使得：
$$a_{p_1} \le a_{p_2} \le \dots \le a_{p_n}$$

交互器是**自适应（adaptive）**的，即数组并非一开始固定，但交互器保证始终存在至少一个元素在 $\{0, 1, 2\}$ 中的数组与之前的所有回答一致。你输出的排列必须对于所有与历史回答一致的合法数组均有效。

#### 交互协议
- 询问格式：`? i j` （$1 \le i, j \le n$）
  - 若 $a_i > a_j$ 返回 `1`；
  - 若 $a_i \le a_j$ 返回 `0`。
- 回答格式：`! p_1 p_2 ... p_n`
输出后请务必刷新缓冲区（`fflush(stdout)` / `cout.flush()`）。

#### 数据范围
$T \le 250, \ 2 \le n \le 500, \ \sum n \le 500$。

### Problem I: Invisible Edges
**时限**: 1.0s | **空间限制**: 1024MB
**题型**: 双阶段交互/通信题（Multi-pass）

#### 题目描述
VegiCat 和 VegiDog 在一个由 $n$ 个点（编号 $1 \sim n$）、$m$ 条边组成的无向森林上玩游戏。
- **第一阶段（VegiCat）**：VegiCat 为每个顶点 $u$ 分配一个整数点权 $a_u \ (1 \le a_u \le 2n)$，点权可以重复。
- 随后，顶点被随机重编号：设 $p_1, p_2, \dots, p_n$ 是 $1 \sim n$ 的一个置换，原先编号为 $u$ 的顶点现在的编号为 $p_u$。原边 $(u, v)$ 变为 $(p_u, p_v)$。每个顶点保留其点权，即若重编号后顶点为 $i$，其点权 $b_i = a_{p^{-1}(i)}$（即 $b_{p_u} = a_u$）。
- **第二阶段（VegiDog）**：VegiDog 只知道点数 $n$ 以及重编号后的点权序列 $b_1, b_2, \dots, b_n$。他不知道原始森林的结构，也不知道置换 $p$。他必须在新编号下还原出所有的 $m$ 条边。

请为两位玩家设计一个对任意合法森林和任意置换 $p$ 都适用的通用通信策略。

#### 运行流程
程序将运行两次：
1. 第一次以 VegiCat 身份运行，输入第一行包含字符串 `cat`；需为每个用例输出每个顶点的权值 $a_1, \dots, a_n$。
2. 第二次以 VegiDog 身份运行，输入第一行包含字符串 `dog`；需根据 $b_1, \dots, b_n$ 输出边数 $m$ 及所有重编号后的边 $(u, v)$。

#### 数据范围
$T \le 10^4, \ 1 \le n \le 2 \times 10^5, \ 0 \le m < n, \ \sum n \le 2 \times 10^5$。

### Problem J: Joint Relocation
**时限**: 4.0s | **空间限制**: 1024MB

#### 题目描述
VegiCat 的公司有 $n$ 名员工，分属于 $k$ 个非空团队。员工们住在一条笔直的马路上（数轴）。
VegiCat 想为他们安排两个集会地点。
他将 $k$ 个团队划分为两个集合 $A$ 和 $B$（每个团队恰好属于一个集合，任一集合可以为空）。他在数轴上为集合 $A$ 选定一个实数坐标集会点，为集合 $B$ 选定一个实数坐标集会点。
同一团队的所有员工必须前往同一个集会点。

对于住址坐标列表 $S = (x_1, x_2, \dots, x_m)$，所有员工前往同一个最优集会点的最小总路程为：
$$M(S) = \min_{p \in \mathbb{R}} \sum_{j=1}^m |x_j - p|$$
当 $S$ 为空时 $M(S) = 0$。

请帮助 VegiCat 在所有将 $k$ 个团队划分为两个集合的方案中，求出 $M(S_A) + M(S_B)$ 的最小值。

#### 输入格式
第一行输入 $T \ (1 \le T \le 3 \times 10^5)$。
每个测试用例第一行包含两个整数 $n, k \ (1 \le k \le n \le 3 \times 10^5)$。
接下来 $k$ 行描述每个团队：第 $i$ 行先给出团队人数 $m_i$，随后是 $m_i$ 个整数表示各成员的坐标 $x_{i, j} \ (1 \le x_{i, j} \le 10^7)$。保证 $\sum m_i = n$。
保证所有用例 $\sum n \le 3 \times 10^5$。

#### 输出格式
对每个测试用例，输出一行一个整数表示最小可能的总移动距离。

### Problem K: Keep Your Distance
**时限**: 1.0s | **空间限制**: 1024MB

#### 题目描述
数轴上有 $n$ 个地雷，第 $i$ 个地雷位于整数坐标 $a_i$。地雷按坐标顺序编号，即 $a_1 \le a_2 \le \dots \le a_n$（坐标可重叠）。
VegiCat 依次排查地雷 $1, 2, \dots, n$。对于地雷 $i$，他选择一个整数坐标 $b_i$ 作为探测位置（$b_i$ 可以为负数或 0）。该次排查的误差为 $|a_i - b_i|$。

对于每个 $2 \le i \le n$，给定整数 $l_i$，要求相邻两次排查位置之间必须保持足够的安全距离，即：
$$|b_i - b_{i-1}| \ge l_i$$

请帮助 VegiCat 最小化所有排查中产生的**最大误差**：
$$\min_{b_1, \dots, b_n \in \mathbb{Z} \atop |b_i - b_{i-1}| \ge l_i} \left( \max_{1 \le i \le n} |a_i - b_i| \right)$$

#### 输入格式
第一行包含整数 $T \ (1 \le T \le 10^4)$。
每个测试用例第一行包含一个整数 $n \ (2 \le n \le 10^5)$。
第二行包含 $n$ 个整数 $a_1, a_2, \dots, a_n \ (1 \le a_i \le 10^9)$。
第三行包含 $n-1$ 个整数 $l_2, l_3, \dots, l_n \ (1 \le l_i \le 10^9)$。
保证 $\sum n \le 10^5$。

#### 输出格式
对每个测试用例，输出最小可能的最大测试误差。

### Problem L: Long Slides
**时限**: 2.0s | **空间限制**: 1024MB

#### 题目描述
在无限二维网格上，机器人初始位于格子 $s = (s_x, s_y)$，目标是到达 $t = (t_x, t_y)$。
机器人依照长度为 $|p|$ 的指令串 $p$ 移动，每个字符为 `L`、`R`、`U`、`D` 之一。

在机器人开始移动前，你可以在网格的不同单元格放置**最多 $|p|$ 个障碍物**。每个障碍物的坐标 $(x, y)$ 必须满足 $-2 \times 10^9 \le x, y \le 2 \times 10^9$。起点 $s$ 和终点 $t$ 均不能放置障碍物。障碍物放置后全程固定。

机器人依次执行指令 $p_1, p_2, \dots, p_{|p|}$。每次执行时，它沿指定方向滑行，直到遇到障碍物前一格停下：
- 若指定方向的相邻下一格就是障碍物，机器人原地不动并完成该指令；
- 若指定方向的前方没有任何障碍物，机器人将无限滑行下去（此时放置方案非法）；
- 机器人中途经过 $t$ 并不会提前停止，必须执行完所有指令。

请构造一种障碍物放置方案，使得机器人执行完所有指令后恰好停在 $t$，或者报告无解。

#### 输入格式
第一行输入 $T \ (1 \le T \le 10^5)$。
每个测试用例包含三行：
1. 起点坐标 $s_x, s_y \ (-10^9 \le s_x, s_y \le 10^9)$；
2. 终点坐标 $t_x, t_y \ (-10^9 \le t_x, t_y \le 10^9)$；
3. 指令串 $p \ (1 \le |p| \le 10^5)$。
保证 $\sum |p| \le 10^5$。

#### 输出格式
若无解输出 `NO`。
若有解第一行输出 `YES`，第二行输出障碍物数量 $k \ (0 \le k \le |p|)$，接下来 $k$ 行每行输出一个障碍物坐标 $(x_i, y_i)$。

### Problem M: Minimum Records
**时限**: 1.0s | **空间限制**: 1024MB

#### 题目描述
给定 $n$ 个闭区间 $[l_1, r_1], [l_2, r_2], \dots, [l_n, r_n]$。
你需要构造一个序列 $a_1, a_2, \dots, a_n$，满足 $l_i \le a_i \le r_i \ (1 \le i \le n)$。

若位置 $i$ 满足对于所有 $1 \le j < i$ 均有 $a_i > a_j$，则称位置 $i$ 为一个**破纪录位置（Record Position）**。特别地，位置 1 始终是破纪录位置。

请帮助 VegiCat 最小化破纪录位置的数量，并输出该最小值。

#### 输入格式
第一行包含一个整数 $T \ (1 \le T \le 10^4)$。
每个测试用例第一行包含一个整数 $n \ (1 \le n \le 10^6)$。
接下来 $n$ 行，每行包含两个整数 $l_i, r_i \ (-10^9 \le l_i \le r_i \le 10^9)$。
保证 $\sum n \le 10^6$。

#### 输出格式
对每个测试用例，输出最少可能的破纪录位置个数。
