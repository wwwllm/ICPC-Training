# 最后一个数

## 题目描述

初始有一个集合 $\{1,2,\dots,n\}$。

每次操作选出集合中两个数 $x,y$，把它们从集合中删去，并加入 $|x-y|$。

经过 $n-1$ 次操作后，集合中恰好只剩下一个数。问这个数**能否恰好等于** $k$。

## 输入格式

第一行一个整数 $t$，表示数据组数。

接下来 $t$ 行，每行两个整数 $n,k$。

## 输出格式

对每组数据输出一行，如果最后剩下的数可以为 $k$，输出 `Yes`；否则输出 `No`。

## 数据范围

- $1 \le t \le 10^5$
- $1 \le n \le 10^9$
- $0 \le k \le 10^9$

## 输入输出样例

**样例 1**

输入：
```
5
3 2
3 1
2 1
4 4
6 6
```

输出：
```
Yes
No
Yes
Yes
No
```

**样例解释**

- $n=3,k=2$：先选 $1,2$，得到 $1$，集合变为 $\{1,3\}$，再选 $1,3$ 得到 $2$，可以。
- $n=3,k=1$：所有数之和为 $6$ 是偶数，而每次操作后「所有数之和」的奇偶性不变，所以最后剩下的数一定是偶数，$1$ 不可能。
- $n=2,k=1$：唯一一次操作是 $|1-2|=1$，可以。
- $n=4,k=4$：选 $2,3$ 得 $1$，集合变为 $\{1,1,4\}$；选 $1,1$ 得 $0$，集合变为 $\{0,4\}$；最后 $|0-4|=4$，可以。
- $n=6,k=6$：$\frac{6\times 7}{2}=21$ 是奇数，最后剩下的数一定是奇数，$6$ 不可能。

## 说明/提示

- 输出区分大小写（`Yes` / `No`）。
- $n=10^9$ 时 $\frac{n(n+1)}{2}\approx 5\times10^{17}$，**用 64 位整数计算不会溢出**。
- 时间限制 $1$ 秒，空间限制 $256$ MB。
