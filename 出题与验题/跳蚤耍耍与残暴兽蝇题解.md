# 题解
对于每一个询问选择一个关卡 $i$ 玩 $k(k \le \lfloor A / a_i \rfloor)$ 次剩余用1补齐的花费：$$\text{Cost} = A - k(a_i - b_i)$$
所以对于每一个询问的答案就是：$$\text{Ans} = A - \max_{i=1}^{m} \left( \max(0, \lfloor A / a_i \rfloor \cdot (a_i - b_i)) \right)$$
单次询问 $A$ 时，我们要找的是 $\max_{i} \lfloor A / a_i \rfloor \cdot (a_i - b_i)$ ，可以用线段树或者前缀和直接预处理出每一个A的 $\max_{i} \lfloor A / a_i \rfloor \cdot (a_i - b_i)$ 。

# 代码
```cpp
#include <bits/stdc++.h>
#define int long long
using namespace std;

const int N = 5e5;
void solve()
{
    int n;
    cin >> n;
    vector<array<int, 2>> a;
    for (int i = 0; i < n; i++)
    {
        int x, y;
        cin >> x >> y;
        if (x > y)
            a.push_back({x, y});
    }
    vector<int> dp(N + 1);
    for (auto [x, y] : a)
    {
        int d = x - y;
        for (int i = x; i <= N; i += x)
        {
            dp[i] = max(dp[i], (i / x) * d);
        }
    }
    for (int i = 1; i <= N; i++)
    {
        dp[i] = max(dp[i], dp[i - 1]);
    }
    int q;
    cin >> q;
    while (q--)
    {
        int x;
        cin >> x;
        cout << x - dp[x] << '\n';
    }
}
signed main()
{
    ios::sync_with_stdio(0), cin.tie(0), cout.tie(0);
    solve();
    return 0;
}
```
